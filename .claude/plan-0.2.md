# План версии 0.2

Следующая версия после [0.1](./plan-0.1.md). Бриф — [project-brief.md](./project-brief.md),
разбор движков — [engine-research.md](./engine-research.md). Решения 0.1 остаются в силе, если
здесь не сказано иначе; этот файл фиксирует только новое.

Задачи этапов, реестр и журнал 0.2 — в [tasks/version-0.2/](./tasks/version-0.2/). Техдолг
общий для всех версий — [tasks/tech-debt.md](./tasks/tech-debt.md).

**Статус:** спланирована (Павел, 2026-10-12–13): решения — в разделе «Решения планирования»,
спецификации этапов — в таблице «Этапы». Этапы 0–3 сданы; следующий — этап 4.

---

## Фокус

**Интерфейс жанра на демо-сцене.** 0.1 дала играбельную демо-сцену — две сцены, музыка, сейв и
настройки; развилка пока есть только в dev-сцене `branching`. Системные кнопки панели (Auto,
Skip, History, Load) — заглушки. В 0.2 игрок получает всё, чего ждёт от новеллы, — на
расширенной демо-сцене. Настоящий сюжет — в 0.3.

Принцип брифа не меняется: движок растёт только из того, что нужно. Каждая новая абстракция в
`engine/` должна быть нужна функции из списка ниже.

## Не в 0.2

- **Настоящий сюжет** — 0.3.
- **Choices** — история выборов: кнопка остаётся заблокированной.
- Экспорт сейва в файл, достижения.

## Решения 0.1, которые продолжают действовать

- Целевой браузер — **Chrome**.
- Значения дизайна — в токенах темы. Экраны 0.2 заказываются в Claude Design (решение 9); чего
  в макетах нет — рисуется в их языке.
- До слотов «Сохранить» пишет в слот автосейва — подтверждение, а не точка возврата.
- Процесс: ветка на этап, Павел коммитит, решения, влияющие на структуру, — вопросом до
  реализации; при работе этапом целиком спорные моменты собираются в реестр к ревью.
- При неоднозначности в движке — как в Ren'Py.
