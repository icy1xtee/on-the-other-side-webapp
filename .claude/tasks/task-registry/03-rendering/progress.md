## Риски и спорные моменты — к ревью

1. **`useEffectEvent` из React 19.2.8 отдавал устаревший обработчик** внутри `observer`:
   Space вызывал `finish()` давно ушедшей реплики, печать застревала на пустой строке.
   Поймано сценарием CDP. Заменён на классический приём: ref с последним обработчиком,
   обновляемый в `useLayoutEffect`. Причину в React не раскапывал — если `useEffectEvent`
   понадобится снова, проверять в связке с `observer`.
2. **Масштаб ×1.5** — моя интерпретация: дизайн свёрстан как адаптивная страница, без
   фиксированного кадра. При 1920 в браузере он мельче, чем наш кадр. Если задумывался
   именно мелкий текст — поменять токены.
3. **Системные кнопки — неактивные заглушки** с подсказкой «Скоро»: Auto, Skip, History,
   Save, Load, Choices по дизайну. В дизайне есть второй набор (Auto … Settings) в правом
   верхнем углу сцены — не перенесён, дублирует панель.
4. **Подписи кнопок на английском, как в дизайне**, при русских меню и тексте игры.
5. **Не перенесено из дизайна:** кнопка VOICE (озвучки нет), таймкод «CH.04 · SCENE 12 ·
   02:41:18», аватар игрока в шапке.
6. **У Анны один рисунок на все три эмоции** — другого арта нет. Замена по тегу видна как
   один спрайт, но сама смена эмоции глазами не различима. Портрет — маленький (75×134) из
   дизайна.
7. **Демо-арт — персонаж из дизайна («Mila»)**, в контенте он Анна.
8. **Esc уводит в главное меню**, как в спецификации. В Ren'Py Esc открывает игровое меню
   (сейв, загрузка, настройки) — вернуться к этому вместе с этапами 5–6.
9. **CSS шрифтов — 70 КБ**: `@font-face` для всех наборов, включая вьетнамский. Скачиваются
   только нужные файлы; урезать нельзя без потери `unicode-range` (см. контекст).
10. **Клик проверяется только `closest(...)`.** Неактивные кнопки в Chrome клик вообще не
    отдают — результат тот же: диалог не продвигается.
