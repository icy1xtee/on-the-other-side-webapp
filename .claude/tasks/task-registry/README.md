# Реестр задач

Живое состояние работ по этапам. Одна папка на этап, имя — как у файла задачи
(`01-shell` ↔ [../01-shell.md](../01-shell.md)).

| Файл | Что в нём | Когда меняется |
|---|---|---|
| `context.md` | полный контекст этапа: цель, границы, согласованные решения, на что опираемся, ограничения, критерии готовности | когда принимается решение или меняются границы |
| `progress.md` | ветка, статус шагов, журнал по шагам, открытые вопросы с ответами | после каждого шага |

**Как связано с остальными документами:**

- [../NN-*.md](../) — исходная спецификация этапа, написанная при планировании. Не
  переписывается; если реальность разошлась, расхождение фиксируется здесь, в `context.md`.
- [../progress.md](../progress.md) — сводка по всем этапам. Сюда попадает итоговая запись в
  конце этапа, подробности остаются в реестре.
- [../../plan-0.1.md](../../plan-0.1.md) — правится, если решение затрагивает архитектуру.

Задача по папке реестра должна читаться без истории чата: открыл `context.md` и
`progress.md` — понял, что делаем, что сделано и что дальше.
