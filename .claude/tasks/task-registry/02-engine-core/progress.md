### Что проверяет каждый шаг

1. Тесты: `requiresInteraction`, `resolveText`; типовой тест — команда с суженными id
   присваивается движковой, `when` не ломает вариантность; исчерпывающий `switch`.
2. Тесты: `scene` очищает спрайты и ставит фон; `show` с тем же тегом заменяет, с другим —
   добавляет; `hide` убирает, несуществующий тег не роняет; `set` меняет переменную; `music`
   пишет трек в состояние; состояние сериализуется в JSON и обратно без потерь.
3. Тесты: сцена компилируется в программу; `jump` в несуществующую сцену и несуществующая
   стартовая сцена — понятная ошибка при регистрации.
4. Тесты: мгновенные применяются подряд, выполнение встаёт на `say`; следующий проход идёт
   дальше; `jump` переключает сцену и сбрасывает шаг; конец сцены — `end`; бесконечный
   `jump` упирается в лимит с понятной ошибкой.
5. Тесты: демо-сцена проходит от старта до `end`; опечатка в id и чужая эмоция — ошибка
   компиляции (типовой тест).
6. Поведение не меняется: меню → игра работает, `lint` и `typecheck` чистые.
7. «Новая игра» запускает демо-сцену (в DevTools видно состояние); визуально пока ничего —
   рендер на этапе 3.
