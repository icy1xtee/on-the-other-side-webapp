# Этап 6. Аудио и настройки — контекст

Исходная спецификация — [../../06-audio-settings.md](../../06-audio-settings.md). Ход работ —
[progress.md](./progress.md).

---

## Цель

Музыка играет и не спотыкается об autoplay-политику; громкость и скорость текста меняются
сразу и переживают перезапуск; язык запоминается. «Новая игра» при существующем сейве
спрашивает подтверждение (решение ревью этапа 5).

## Опирается на

- **Этап 2** — эффекты движка `{ type: 'music', asset, ifChanged }` и `{ type: 'sfx', asset }`,
  `state.audio.music` в состоянии.
- **Этап 5** — сейв хранит `audio.music`; `continueGame` выполняет одну сохранённую команду,
  без эффектов по дороге; `shared/lib/storage.ts`, ключи `ots:`.
- **Этап 3** — `useTypewriter`, i18next, `PillButton`, `u()`; демо-трек — от Павла
  (`.claude/ref/media/music/main-demo.mp3`).

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Где аудио | Не в `engine/` (там нет DOM), а `shared/lib/audio.ts` — единственный файл, знающий howler. `AudioOutput`: `playMusic(src, { ifChanged })`, `playSound(src)`, `setVolumes`. Движок отдаёт эффекты, `GameStore` их проигрывает (ids → URL через `presentation.assets.music / sounds`) | по факту (спецификация писала `engine/audio`) |
| Каналы | `music` — один зацикленный трек, кроссфейд 500 мс (`theme.timing.transitionMs`); `sound` — звуки поверх друг друга. Как каналы Ren'Py | спецификация |
| `ifChanged` | Тот же трек с `ifChanged` не перезапускается. «Продолжить» восстанавливает музыку из `state.audio.music` с `ifChanged` — после меню трек начинается заново, но внутри игры (переход `intro` → `walk`) играет тот же экземпляр (проверено) | спецификация |
| Музыка потоком | `html5: true`: трек на 5 МБ не декодируется в память целиком (рекомендация README howler для больших файлов) | по факту |
| Autoplay | Музыка стартует из клика («Новая игра», «Продолжить») — после жеста браузер пускает звук. На отказ — `onplayerror` → повтор на `unlock` (рецепт README howler). Проверено в Chrome; Firefox на машине нет | спецификация |
| Меню | Своей музыки нет: выход в меню — затухание 500 мс, трек выгружается | по факту |
| Громкость | Итоговая = общая × канал: `Howler.volume(master)` × громкость канала. По умолчанию общая 100 %, музыка 50 % (пример из документации Ren'Py), звуки 100 %. Ползунки 0–100 % шагом 5 % | по факту, к ревью |
| Скорость текста | 10–100 симв/с шагом 1 и последняя засечка «Мгновенно» (0, как `text_cps = 0` в Ren'Py). По умолчанию 38 — скорость из дизайна (Ren'Py в документации ставит 40). Показывается числом: «38 симв/с». Смена посреди реплики продолжает печать с того же места | по факту, к ревью |
| `SettingsStore` | `masterVolume`, `musicVolume`, `soundVolume`, `textCps`, `language`; ключ `ots:settings`, отдельно от сейва; каждое изменение пишется сразу. Чтение — по полю через `zod/mini`: битое поле берёт дефолт, остальные живут | спецификация |
| Язык | В настройках и запоминается; переключатель RU / EN остался и в углу меню — оба пишут в `SettingsStore`; i18next стартует с языком из настроек | план этапа 6 |
| Окно настроек | `shared/ui/Modal` + `features/change-settings/SettingsControls` → `widgets/settings-overlay`. Открывают: Esc и шестерёнка в игре, «Настройки» в меню. В игре в окне есть «Главное меню» — как game menu Ren'Py | спецификация + по факту |
| Esc в игре | Открывает настройки (было: сразу главное меню, решение этапа 3). Главное меню — кнопкой в окне. Esc в окне закрывает его | план этапа 6 |
| Модальность | `UiStore.overlay` (`'settings' \| 'confirmNewGame' \| null`). Пока окно открыто, игра не принимает ни кликов, ни клавиш: `Modal` ловит Esc в фазе capture и гасит клики внутри себя, слои под окном — `inert` (Tab туда не попадает) | по факту |
| Подтверждение «Новой игры» | Есть что продолжать — `ConfirmDialog` «Начать заново? Сохранённая игра будет перезаписана: слот сохранения один». Отмена, Esc и клик мимо — ничего не делают | ревью этапа 5 |
| Звук `door` | Файла нет — `sounds: {}`, звук молчит; появится файл — заиграет | по факту |
| Демо-трек | `main-demo.mp3` → `src/assets/music/theme.mp3` как есть, 5 МБ — в [техдолг](../../tech-debt.md), п. 2 | Павел |

## Что вошло

- `shared/lib/audio.ts` (howler, `AudioOutput`, `Volumes`); `howler` 2.2.4, `@types/howler`.
- `content/assets.ts` — `music.theme`, `sounds` (пусто); `assets/music/theme.mp3`.
- `GameStore` — `audio` в опциях, проигрывание эффектов, музыка на «Продолжить»;
  `Presentation.assets.music / sounds`.
- `app/stores/SettingsStore.ts` (+ тест), `UiStore.overlay`, `RootStore` — `settings`,
  громкость в плеер через `autorun`, язык в i18next через `reaction`, `requestNewGame`,
  `toMainMenu` (затухание музыки); `testDoubles.ts` для тестов сторов.
- `shared/ui/Modal.tsx`, `shared/ui/Slider.tsx`; `features/change-settings/` —
  `SettingsControls`, `SettingsRows`; `widgets/settings-overlay/`, `widgets/confirm-dialog/`.
- `useAdvanceDialogue` — скорость из настроек, Esc → настройки, ничего не проходит в игру при
  открытом окне; `useTypewriter` — смена скорости посреди реплики; `Stage` — `modal` (`inert`).
- `MainMenuPage` читает сторы сам (как `GamePage`); `LanguageSwitch` — через настройки;
  `initI18n(story, language)`; `STORAGE_KEYS.settings`; токены `modal`, `slider`, цвета окна.

## Что не вошло

- Тумблер «без звука» (у Ren'Py есть «Mute All») — общая громкость в ноль делает то же.
- Звуковые файлы: `door` молчит.
- Firefox: не установлен — autoplay проверен только в Chrome.
- Дизайн окон настроек и подтверждения — черновик в языке панели реплики.

## Готово, когда

- [x] музыка стартует после «Новая игра» и не блокируется политикой автоплея — Chrome
      (CDP, настоящий клик): трек `playing`, громкость 0.45 по настройке; Firefox — не проверен
- [x] загрузка сейва внутри той же сцены **не** перезапускает трек — `ifChanged`; переход
      `intro` → `walk` с `music('theme', { ifChanged })` — тот же экземпляр трека
- [x] смена сцены с другой музыкой — кроссфейд 500 мс, выход в меню — затухание
- [x] ползунки громкости влияют на звук немедленно — `autorun` → `setVolumes`, тест и CDP
- [x] скорость текста меняется немедленно на текущей реплике — CDP: 12 → 14 → 22 знака
      за 150 мс после смены, без сброса
- [x] настройки сохраняются после перезапуска браузера — язык и громкость пережили
      перезагрузку
- [x] очистка сейва не сбрасывает настройки, и наоборот — CDP, оба направления
- [x] «Новая игра» при существующем сейве спрашивает подтверждение
