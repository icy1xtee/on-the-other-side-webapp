# Этап 1. Каркас: кадр, тема, экраны — контекст

Исходная спецификация — [../../01-shell.md](../../01-shell.md). Ход работ —
[progress.md](./progress.md). Этот файл — полная картина этапа на текущий момент.

---

## Цель

Пустой кадр 16:9 с чёрными полосами по краям, тема с типизированными токенами и переход из
главного меню в игру. После этапа у приложения есть «скелет», в который на этапе 3 встанет
рендер сцены.

## Где этап в роадмапе 0.1

- **Опирается на этап 0** (готов, PR #1): Vite 8 + React 19 + TS 6, MobX, styled-components с
  displayName через Oxc, алиас `@/*`, oxlint с границами `engine/`, Prettier, Vitest.
- **Нужен этапу 2** только корневой стор: туда добавятся `GameStore` и `StageStore`.
- **Нужен этапу 3** почти целиком: слои `Stage` (фон → спрайты → UI → оверлей), токены
  диалогового окна и выборов, `GamePage`.
- **Нужен этапу 6**: `UiStore.isSettingsOpen` — задел под оверлей настроек.

## Что входит

1. **Тема и токены** — `theme.ts`, типизация `DefaultTheme`, `ThemeProvider`.
   Группы токенов (список подсказан `gui.rpy` из Ren'Py):

   | Группа | Токены |
   |---|---|
   | Геометрия кадра | ширина и высота кадра — из `shared/config/stage.ts` |
   | Цвета | фон, текст реплики, имя говорящего, акцент, фон и рамка диалогового окна, idle/hover вариантов выбора |
   | Типографика | семейство, размер реплики, **размер имени отдельно**, размер интерфейсного текста, межстрочный интервал |
   | Диалоговое окно | высота, внутренние отступы, позиция по вертикали, позиция имени |
   | Выборы | ширина варианта, зазор между вариантами |
   | z-индексы | фон, спрайты, UI, оверлей |
   | Длительности | переход 500 мс, скорость текста по умолчанию (cps) |

   Все размеры — в пикселях макета 1920×1080: кадр масштабируется целиком.
2. **Глобальные стили** — минимальный reset, `html, body, #root` на 100% высоты,
   `overflow: hidden`, чёрный фон (это и есть letterbox), `user-select: none`, сглаживание
   шрифтов.
3. **Stage** — `useStageScale()` на `ResizeObserver` поверх готовой `getStageScale`; внешний
   контейнер `position: fixed; inset: 0` с центрированием; сам кадр 1920×1080 с
   `transform: scale(k)`; четыре слоя `position: absolute; inset: 0` по z-индексам темы.
4. **Сторы** — `RootStore` (пока только `ui`), `StoreProvider` на React context, `useStores()`;
   `UiStore`: `screen: 'menu' | 'game'`, `isSettingsOpen`, экшены перехода.
   MobX: классы + `makeAutoObservable`, без декораторов.
5. **Экраны** — `MainMenuPage` (название, «Новая игра», «Продолжить» и «Настройки»
   неактивны), `GamePage` (пустой `Stage`), `shared/ui/Button`. Переключение полем в сторе,
   без роутера.

## Что не входит

- Реальный дизайн, шрифты и палитра — их делает Claude Design (см. ниже).
- Любой контент сцены, диалоговое окно, спрайты — этап 3.
- Оверлей настроек — этап 6; здесь только флаг в `UiStore`.
- Горячие клавиши — этап 3.

| Решение | Когда | Суть |
|---|---|---|
| Визуальный стиль | 2026-10-09 | **Нарочито черновой**, как плейсхолдеры арта. Дизайн — отдельно, когда заработает механика |
| Дизайн и шрифты | 2026-10-09 | Отданы в **Claude Design**, генерируется. Пока используем системный стек и черновую палитру; токены проектируются так, чтобы дизайн заменил только значения, а не структуру |
| Ветки | 2026-10-09 | **Одна ветка на этап**, внутри — коммит на шаг (Conventional Commits), PR в `main` в конце этапа |
| Размеры кадра | 2026-10-09 | Единственный источник — `shared/config/stage.ts` (`STAGE_WIDTH`, `STAGE_HEIGHT`); тема на него ссылается, не дублирует |
| Типизация темы | 2026-10-09 | `DefaultTheme extends AppTheme`, `AppTheme = typeof theme` — структура описана один раз, в объекте темы |
| Единицы в токенах | 2026-10-09 | Размеры — числа в px макета 1920×1080, `px` дописывается в стилях; длительности — `…Ms` |
| Черновая геометрия | 2026-10-09 | Диалог и выборы — дефолты `gui.rpy` Ren'Py для 1920×1080 |

## Что уже есть в коде

- `src/shared/config/stage.ts` — `STAGE_WIDTH = 1920`, `STAGE_HEIGHT = 1080`.
- `src/shared/lib/stageScale.ts` — `getStageScale(w, h) = min(w / 1920, h / 1080)`, покрыта
  тестом.
- `src/app/styles/theme.ts` — тема с черновыми токенами, `AppTheme` (шаг 1).
- `src/styled.d.ts` — расширение `DefaultTheme` (шаг 1).
- `src/app/App.tsx` — `ThemeProvider` + заглушка-заголовок; на шаге 4 сменится переключением
  экранов.
- `src/main.tsx` — точка входа со `StrictMode`, остаётся в `src/` (на неё ссылается
  `index.html`).

## Ограничения

- FSD-слои импортируют только вниз: `app → pages → widgets → features → entities → shared`.
  Линтером не проверяется — держим руками.
- UI не тестируется; тесты — только на чистую логику.
- Код и комментарии на английском, текст интерфейса игры — на русском.
- Каждый шаг оставляет проект рабочим: `lint`, `typecheck`, `test`, `format:check`, `build`.

## Риски

- **Мыльный текст при дробном `scale`.** Проверить на абзаце русского текста при
  `scale ≈ 0.63` и `1.0`. Если заметно — переход на единицы контейнера (`cqw`).
- **Полупиксельная кайма** по краям кадра при дробном масштабе и `devicePixelRatio`.
- **Подмена шрифта после дизайна** поменяет переносы строк. На этапе 1 текста мало, риск
  переезжает на этап 3.
