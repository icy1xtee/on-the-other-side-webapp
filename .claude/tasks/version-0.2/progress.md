**Сделано:**

- **Ревизия** — слои FSD чистые (скрипт по импортам), мёртвого кода, лишних токенов и устаревших

**Проверено:** `lint`, `typecheck`, `test` (251), `format:check`, `build` (JS 537 КБ / gzip
161 КБ), `e2e` (18); прод-сборка — демо целиком со всеми функциями 0.2, без ошибок и упавших
запросов; «Управление» на пяти размерах и на английском. Спорные моменты (9) — в реестре.

#### Ретроспектива 0.2

**Что оказалось неудобным:**

1. **Правило слоёв держится вручную.** На этапе 7 «Управлению» понадобился список клавиш
   соседней фичи — вовремя заметили, список ушёл в `shared/config`. Проверял скриптом из
   scratchpad. Кандидат — правило `no-restricted-imports` по слоям в `.oxlintrc.json`.
2. **`ReadingStore` — самый большой стор** (343 строки): Auto, Skip, откат, ожидание перехода.
   Пока цельный; озвучка («не прерывать голос») и NVL пойдут сюда же — следить.
3. **Русская строка — ключ.** Правка реплики сиротит перевод, делает её непрочитанной и
   перезапускает сцену в сейвах (с откатом, обрезанным по изменённой сцене). На настоящем сюжете
   правки после выхода — осознанно; кандидат на потом — стабильный id реплики.
4. **Проверки «глазами» — разовыми скриптами** (снимки на четырёх размерах, состояние howler,
   начертания шрифтов) — в scratchpad, между сессиями пропадают. e2e закрывают пути, но не вид.
5. **Сборка растёт:** JS 446 → 537 КБ (gzip 139 → 161), предупреждение Vite о чанке > 500 КБ.
   Кандидат — разделы игрового меню отдельным чанком.
6. **Сеть Павла блокирует kenney.nl, itch.io, archive.org** — звуки взяли с OpenGameArt, сборку
   ffmpeg — вне репозитория (рецепт — в `CREDITS.md`).
7. **Howler с причудами:** об одном отказе автоплея сообщает дважды, на разблокировке
   перезапускает аудио. Изоляция в одном файле (`audio.ts`) окупилась — чинили в одном месте.

**Что из Ren'Py сработало:**

- **точка отката на каждое взаимодействие** и журнал при точках — откат сам обрезает «Историю»,
  сейв — путь целиком, загрузка — как откат (кадр сразу, музыка `if_changed`);
- **`persistent`** для прочитанного, **`skip_unseen = False`**, **`afm`** с временем на чтение,
  стоп Skip и Auto на развилке;
- **`with` как эффект** взаимодействия — переход не попадает в сейв, при откате и Skip не
  играет;
- **`config.main_menu_music` с `if_changed`** и **`main_menu_stop_channels`** — музыка без
  перерыва досталась почти бесплатно;
- **`config.keymap`** — один список клавиш для обработчиков и экрана помощи;
- **game menu одним окном** с разделами — пять разделов без новых окон.

**Что оказалось лишним для нашего масштаба:**

- несколько `with` подряд (в Ren'Py — по очереди): в демо до реплики всегда один, хватило
  «играет последний»;
- глубины 128 и 250 — демо их не достаёт (38 реплик), но стоят копейки;
- `STEP_LIMIT` по-прежнему ни разу не сработал; `stopMusic` в DSL демо не нужен.

Сознательно не брали и не пожалели: быстрый слот, номера у вариантов, кнопки в углу сцены,
звуки интерфейса.

#### Бэклог 0.3 — предложения

Решаем на планировании 0.3; каждое — вопросом.

- **Настоящий сюжет** — главное 0.3: сцены, тексты, арт, спрайты Милы по эмоциям.
- **Деплой** — GitHub Pages через Actions; рекомендую отдельным маленьким этапом сразу после 0.2
  (вопрос 1 ревью этапа 7).
- **«Выборы»** (история выборов), **озвучка**, **профиль** — сейчас заглушки «появится позже»:
  что из них в 0.3.
- **Свои звуки и трек Opus/OGG** — Павел подложит (техдолг, п. 2).
- **Спорные моменты, отложенные «до реального контента»** — этапы 5 и 6: несколько `with`
  подряд, панель во время `fade`, звуки.
- **Правило слоёв в линтере**, **разделы меню отдельным чанком**.
- **Другие браузеры и macOS** (подпись ⌘ / ⌃) — когда Chrome перестанет быть единственным.
