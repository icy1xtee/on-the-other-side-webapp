## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Демо | 30–40 реплик, 2–3 сцены, одна развилка, ветки сходятся; текст — Claude (решение 1) | планирование, Павел, 2026-10-12 |
| Ретроспектива | Все три: разделить `GameStore`, чтение — в стор, e2e на Playwright (решение 3) | планирование, Павел, 2026-10-12 |
| CI | GitHub Actions на PR (решение 4) | планирование, Павел, 2026-10-12 |
| Порядок шагов | CI → демо → e2e → рефакторинг: тесты страхуют разделение стора | планирование, Павел, 2026-10-12 |
| CI — устройство | `.github/workflows/ci.yml`: на PR в `main` и на push в `main`. Две задачи: «проверки» (`lint`, `typecheck`, `test`, `format:check`, `build`) и e2e. `actions/checkout@v7`, `actions/setup-node@v7` с `node-version-file: .nvmrc` (точная версия — `engine-strict` доволен) и `cache: npm`. Новый push отменяет прогон старого (`concurrency`). Отчёт Playwright — артефактом, только при падении | доки, по факту |
| Браузер в CI | `npx playwright install --with-deps --only-shell chromium`: только headless shell, без кеша — Playwright не советует кешировать (восстановление не быстрее скачивания, системные библиотеки всё равно ставятся) | доки |
| e2e — запуск | Playwright 1.64, Chromium, окно 1280×720 (размер макета). `npm run e2e` = `build` + `playwright test`; `webServer` поднимает `vite preview` на **своём порту 4180** — ручной `preview` на 4173 не мешает; чужой сервер не переиспользуется. В CI одна повторная попытка, трасса — при падении | по факту |
| e2e — как ищут | По ролям и тексту. Текст реплики в панели дважды — невидимая копия держит размер (этап 0), поэтому реплика ищется среди видимых (`filter({ visible: true })`). Тексты демо, на которые опираются тесты, — в одном файле `e2e/game.ts` | по факту |
| e2e — сценарии | Три из спецификации (прохождение до главного меню, развилка кликом и цифрой, «Продолжить» после перезагрузки) — с мгновенным текстом. Плюс **«чтение на скорости»**: нажатие посреди строки показывает её целиком, следующее — дальше; допечатанная строка уходит с одного нажатия. Без него связку печатной машинки и стора не страхует ничто: проверено — отключённый отчёт машинки этот тест ловит | по факту; ревью — ок (Павел, 2026-10-13) |
| e2e — TS | `tsconfig.e2e.json` в `tsc -b` (Node + DOM: колбэки страницы); oxlint проверяет `e2e/` сам, Vitest его не трогает | спецификация |
| Демо — сюжет | Под арт (ночная комната с мониторами, ночная улица) и тон макетов: ночь, дождь, стук в дверь, голос «с другой стороны». Три сцены: `intro` «Стук в дверь» (комната) → `walk` «Тихая улица» → `home` «Снова дома» (комната), конец — по исчерпанию, в главное меню | по факту; ревью — ок (Павел, 2026-10-13) |
| Демо — развилка | У двери, вопрос задаёт Мила: «Открыть дверь» / «Спросить, кто там» / «Промолчать». Ветки — блоки `then` по 4 реплики, каждая кончается `goTo('walk')`. Ответ — в переменной `doorAnswer` (`'none' \| 'opened' \| 'asked' \| 'silent'`); читать её пока некому. `metMila` и `trust` остались для dev-сцен | по факту; ревью — ок (Павел, 2026-10-13) |
| Демо — объём | 38 реплик (с вопросом развилки), прохождение — 30 при любом ответе. Позиции Милы: центр, справа, слева; все три эмоции | по факту |
| Демо — звуки | Места отмечены: `knock` (стук), `door` (дверь открылась), `steps` (шаги). Файлов нет до этапа 6 — молчат | по факту |
| Разделение `GameStore` | **`GameStore`** — игровой цикл: `state`, `interaction`, `turn`; `newGame`, `continueGame`, `advance`, `choose`; виды `frame`, `line`, `choiceOptions`, `sceneTitle`, `continuePreview`. **`SaveStore`** — автосейв, `resumable` / `canContinue`, «Сохранить» (`saveNow`), `forget` в конце, одно уведомление о недоступном хранилище, часы времени игры. **`presentation.ts`** — чистые функции `frameView`, `lineView`, `optionViews`, `sceneTitle`, `quotedLine` и типы видов. **`audioEffects.ts`** — `playEffects`; «Продолжить» возвращает музыку тем же путём — эффектом с `ifChanged` | по факту |
| «Где игрок» для сейва | `SaveStore.resumable` — всегда состояние на реплике или выборе на экране (пишется на каждой), поэтому «Сохранить» и остановка часов переписывают его сами, без `GameStore`. После конца игры его нет — и сохранять нечего | по факту |
| `continuePreview` | Остался в `GameStore`: превью — прогон движка (`run`) по состоянию сейва плюс представление; `SaveStore` о движке-интерпретаторе и `presentation` не знает | по факту |
| Стор чтения | **`ReadingStore`**: `lineShown` (строка целиком), `choiceOptions` (варианты — после прочтения вопроса; без вопроса — сразу), команды `requestAdvance()`, `finishLine()`, `lineTyped(key)`, `pickOption(n)` для клавиш 1–9. Реплика на экране — по-прежнему `GameStore.line`, её ключ меняется с каждой репликой. Сюда придут Auto и Skip (этап 2) | по факту |
| Конец печати | **UI сообщает стору** (`useTypewriter` → `onTyped`), а не стор считает по времени: машинка остаётся единственным источником времени — rAF, пауза в скрытой вкладке, смена скорости посреди строки. Мгновенный текст стор знает из настроек сам — строка целиком сразу, без кадра ожидания | по факту |
| Хук `useAdvanceDialogue` | Тонкий: клик, Space / Enter → `requestAdvance`, 1–9 → `pickOption`, Esc → меню. Слушатель клавиш читает сторы в момент нажатия — `ref` на «последний обработчик» больше не нужен | по факту |
| Тесты сторов | Общая маленькая история и сборка сторов — `src/app/stores/testStory.ts`. Тесты разнесены: `presentation`, `audioEffects`, `SaveStore`, `GameStore`, `ReadingStore`, `RootStore` | по факту |
| Dev-зависимости | `npm audit fix`: `vitest` 4.1.11, `nanoid` 3.3.20, `source-map-js` 1.2.2 — уязвимостей нет | Павел, ревью 2026-10-13 |

## Что вошло

- **CI** — `.github/workflows/ci.yml`.
- **Демо** — `src/content/scenes/{intro,walk,home}.ts`, названия сцен, `doorAnswer`, звуки `knock` / `door` / `steps`, полный английский.
- **e2e** — `playwright.config.ts`, `tsconfig.e2e.json`, `e2e/` (`game.ts` + `playthrough`, `choice`, `continue`, `reading`), `npm run e2e`.
- **Сторы** — `GameStore` (цикл), `SaveStore`, `ReadingStore`, `presentation.ts`, `audioEffects.ts`, `testStory.ts`; `RootStore` собирает их.
- **UI** — `useAdvanceDialogue` тонкий, `useTypewriter` сообщает о конце печати; `GamePage` берёт сейв и время из `saves`.
- **Документы** — CLAUDE.md (команда `e2e`, четыре TS-проекта, структура сторов, конвенция про тесты UI), README.
