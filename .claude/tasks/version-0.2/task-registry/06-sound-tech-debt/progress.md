### 2026-10-14 · этап целиком · на проверке

Ветка создана Павлом от `main` после PR #17.

**Сделано:**
- **Музыка меню** — `theme` играет в главном меню; меню → игра → меню, «Продолжить» и загрузка — без перерыва (`ifChanged` везде, как `config.main_menu_music` в Ren'Py). На выходе в меню звуки глохнут, как в Ren'Py.
- **Автоплей** — трек ждёт первого клика или клавиши; howler может сообщить об отказе дважды — без защиты заиграли бы две копии трека, теперь ожидание одно.
- **Звуки** — стук, дверь, шаги (Kenney RPG Audio, CC0), собраны ffmpeg в Ogg, `CREDITS.md` рядом; грузятся при старте. kenney.nl, itch.io и archive.org из этой сети не открываются — набор взят с OpenGameArt из загрузки самого Kenney.
- **Шрифты** — свои `@font-face` (Geist 400 и 500, Geist Mono 400; латиница и кириллица): CSS 69,8 → 1,55 КБ. Пункт 1 техдолга закрыт.
- **Трек** — Opus/OGG ещё нет: MP3 остаётся, пункт 2 техдолга открыт.

**Проверено:**
- `lint`, `typecheck`, `test` (244, было 240: музыка и звуки демо по трём веткам, музыка меню и глушение звуков в `RootStore`), `format:check`, `build` (JS 525 КБ / gzip 158 КБ, было 525 / 158; CSS 1,55 КБ, было 69,8).
- `npm run e2e` — 16 тестов, все прошли.
- Прод-сборка в Chromium с `--autoplay-policy=user-gesture-required` (как обычный Chrome), состояние howler по шагам: до жеста трек ждёт, звуки уже загружены; первый клик («Новая игра») — трек играет, один экземпляр, громкость 0,5; позиция трека растёт без сброса через стук, шаги, выход в меню, «Продолжить», раздел «Загрузить»; шаги на выходе в меню обрываются; после перезагрузки трек стартует с первой клавиши (Tab). «Без звука» — общий `masterGain` 0 и `muted` у трека. Ошибок в консоли нет; одно предупреждение howler при старте («HTML5 Audio pool exhausted…») — ожидаемое, пока браузер не разрешил звук.
- Шрифты — обход всех экранов (меню, загрузка, настройки, игра, развилка, сохранение, вопрос, история, английский): грузятся ровно Geist 400 и 500, Geist Mono 400, латиница и кириллица; `document.fonts.check` — да; на снимках кириллица, латиница и моно — Geist. Символы вне наборов (→, ▸) и раньше шли из запасного шрифта.
