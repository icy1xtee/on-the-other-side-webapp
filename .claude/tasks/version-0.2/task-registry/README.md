# Реестр задач 0.2

Живое состояние работ по этапам версии 0.2. Одна папка на этап, имя — как у файла задачи
(`00-design` ↔ [../00-design.md](../00-design.md)). Устроен так же, как
[реестр 0.1](../../version-0.1/task-registry/).

| Файл | Что в нём | Когда меняется |
|---|---|---|
| `context.md` | полный контекст этапа: цель, на что опирается, согласованные решения, что вошло | когда принимается решение или меняются границы |
| `progress.md` | ветка, статус, открытые вопросы с ответами, спорные моменты, журнал | после каждого шага |

**Как связано с остальными документами:**

- [../NN-*.md](../) — исходная спецификация этапа, написанная при планировании. Не
  переписывается; если реальность разошлась, расхождение фиксируется здесь, в `context.md`.
- [../progress.md](../progress.md) — сводка по всем этапам версии.
- [../../../plan-0.2.md](../../../plan-0.2.md) — правится, если решение затрагивает архитектуру.
