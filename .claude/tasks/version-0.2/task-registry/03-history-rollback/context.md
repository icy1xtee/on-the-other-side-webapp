# Этап 3. History и rollback — контекст

Исходная спецификация — [../../03-history-rollback.md](../../03-history-rollback.md). Ход работ —
[progress.md](./progress.md). Решения планирования — [plan-0.2.md](../../../../plan-0.2.md).

## Цель

«История» показывает прочитанное и выборы; «Назад», колесо и PageUp возвращают на прошлую реплику — как в Ren'Py.

## Опирается на

- Этап 0 — каркас игрового меню, кнопка «Назад».
- Этап 1 — разделённые сторы. Снапшот `GameState` — plain data (план 0.1).

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| History | Как в Ren'Py, 250 записей; выбор — строкой; ключи вместо текста; клик по записи никуда не ведёт (решение 13) | планирование, Павел, 2026-10-12 |
| Rollback | 128 шагов, колесо, PageUp / PageDown, кнопка «Назад» (решение 14) | планирование, Павел, 2026-10-12 |
| Развилка | Можно выбрать иначе, вперёд — прежний выбор (решение 15) | планирование, Павел, 2026-10-12 |
| Журнал вне снапшота | Кадр стека помнит свои записи журнала: откат снимает, вперёд возвращает — иначе сейв раздуется | планирование, Павел, 2026-10-12 |
| Где живёт | `src/app/stores/timeline.ts` — чистые функции над `Timeline` `{ checkpoints, current, history }`: `startTimeline`, `arrive`, `goesTheSameWay`, `rollBack`, `rollForward`, `shownEntries`. `GameStore` хранит `timeline` и делает откат: `rollBack()`, `rollForward()`, `canRollBack`, `canRollForward`, `history`, `travelled`. `ReadingStore` — сторона чтения: выключить режимы, показать реплику целиком, на развилке — сразу варианты | по факту |
| Контрольная точка | На каждую interaction: `state` (ровно то, что пишет сейв) + записи журнала, которые принёс приход сюда (выбор, приведший сюда, и показанная реплика) + `chosen`, когда здесь выбрали | по факту |
| Журнал | Реплика (`line`: id говорящего + русская строка), повествование (`narration`), выбор (`choice`: текст варианта). Вопрос развилки — один раз, как реплика. **Текущая реплика — уже в журнале**, как в Ren'Py (`config.history_current_dialogue = True`). Имена — через `presentation`, перевод — в UI | Ren'Py |
| Назад | Восстанавливает точку через `run(состояние)` — как «Продолжить»: кадр сразу, без перехода; музыка — из состояния с `ifChanged`; звуки не играют; автосейв пишет точку, куда откатились. Режимы выключаются. Реплика — сразу целиком; развилка — с вариантами | спецификация |
| Вперёд (колесо вниз, PageDown) | Тот же переход по точкам, что назад: сразу, без звуков, музыка из состояния. Развилку проходит прежним выбором. Дальше пройденного — ничего | по факту; ревью — ок (Павел, 2026-10-14) |
| Клик с откаченной реплики | Обычная игра — с эффектами и переходом. Если путь тот же (реплика; развилка с тем же выбором) — «будущее» остаётся, им можно прокрутить вперёд; другой выбор его стирает | по факту; ревью — ок (Павел, 2026-10-14) |
| Глубина | 128 шагов назад (решение 14). В Ren'Py игрок откатывается на 100 (`config.hard_rollback_limit`), 128 — длина внутреннего лога (`rollback_length`) | планирование; ревью — оставить 128 (Павел, 2026-10-14) |
| «Продолжить» и новая игра | Путь начинается заново: «Назад» недоступна, пока игрок не пройдёт дальше; в журнале — только текущая реплика. Стек и журнал в сейве — этап 4 | спецификация |
| Колесо | `shared/lib/wheelSteps.ts`: щелчок колеса мыши (|deltaY| ≥ 50 px) — шаг; мелкие дельты трекпада суммируются, **один шаг на жест** (сумма ≥ 40 px), жест кончается паузой 200 мс или сменой направления. Строки и страницы (`deltaMode`) переводятся в пиксели. Над открытым окном колесо его прокручивает | по факту |
| Клавиши | PageUp — назад, PageDown — вперёд; зажатые повторяются | Ren'Py |
| «Назад» | Неактивна (серая, `aria-disabled`), когда откатываться некуда; подпись — «Назад», без «скоро». У `DialogueBox` — `inactive`, у `RevealButton` `unavailable` теперь значит и «сейчас нечего делать» | по факту; ревью — ок (Павел, 2026-10-14) |
| Раздел «История» | `features/view-history/HistorySection` по макету `Game Menu` (`isHistory`): реплика — имя и текст, повествование — текст, выбор — метка «Выбор» (моно, капсом) и «→ текст» бирюзой; открывается прокрученным вниз; пусто — «История пуста». Разделы меню в игре — «История», «Настройки»; «История» в панели открывает меню на ней | макет |

## Что вошло

- **Сторы:** `timeline.ts` (+ тест); `GameStore` — путь, откат, журнал; `ReadingStore` — `rollBack`, `rollForward`; `presentation.ts` — `historyView`.
- **`shared`:** `lib/wheelSteps.ts` (+ тест); `config/gameMenu.ts` — раздел `history`; словари — «История», «История пуста», «Выбор».
- **`features`:** `advance-dialogue` — PageUp / PageDown, колесо; `view-history` — раздел «История» (новый).
- **`widgets`:** `dialogue-box` — неактивные кнопки; `game-menu` — раздел «История»; `scene-view` — без перехода при откате.
- **Тема:** `history`, размеры шрифтов журнала, `accentBorderQuiet` (бывший `modeBorder`), `accentTextQuiet`.
- **e2e:** `rollback.spec.ts` — откат колесом, вперёд PageDown, «Назад» и другой выбор; «История» с выбором и после отката.
