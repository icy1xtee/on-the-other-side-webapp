# Этап 0. Новые макеты — контекст

Исходная спецификация — [../../00-design.md](../../00-design.md). Ход работ —
[progress.md](./progress.md). Решения планирования — [plan-0.2.md](../../../../plan-0.2.md).

---

## Цель

Интерфейс по новым макетам Claude Design: экран чтения, главное меню, каркас игрового меню с разделом «Настройки», окно подтверждения, уведомления. Отходы от макета — решения 22, 23, 27.

## Опирается на

- Версия 0.1: `SceneView` (переход кадра), `Modal`, `ConfirmDialog`, `NoticeToast`, `SettingsStore`, `IconButton` + `Tooltip`, `u()` и токены темы.
- Макеты — `.claude/ref/layout-design/`: `Reader`, `Main Menu`, `Game Menu`, `Confirm Dialog`.

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Игровое меню | Одно окно с навигацией (решение 2); каркас и «Настройки» — в этом этапе, остальные разделы — со своими этапами | планирование, Павел, 2026-10-12 |
| Настройки | По макету: заглушки голоса, «Мгновенно» — засечка ползунка, «Задержка автоперехода» и «Пропуск» — этап 2 (решение 20) | планирование, Павел, 2026-10-12 |
| Кнопки панели | Иконки, раскрываются с подписью при наведении и фокусе (решение 22) | планирование, Павел, 2026-10-12 |
| Кнопки в углу сцены | Не делаем (решение 23) | планирование, Павел, 2026-10-12 |
| Аватар | Заглушка «появится позже» (решение 24) | планирование, Павел, 2026-10-12 |
| Язык | В настройках, «Экран»; переключателя в углу меню нет (решение 25) | планирование, Павел, 2026-10-12 |
| Мета-строка | Сцена · время игры; в карточке «Продолжить» — дата и время (решение 26) | планирование, Павел, 2026-10-12 |
| Номера у вариантов | Нет, точка из 0.1 (решение 27) | планирование, Павел, 2026-10-12 |
| Esc | Игровое меню; до этапа 4 — на «Настройках» (решение 28) | планирование, Павел, 2026-10-12 |
| Миниатюра кадра | Из сейва, той же отрисовкой, что сцена (решение 11) — отрисовка кадра переехала в `entities/frame` | планирование, Павел, 2026-10-12 |
| Раскрытие подписи | `shared/ui/RevealButton`: подпись открывается слева от иконки за 180 мс и **толкает соседей влево** — ряд прижат к правому краю, иконка открытой кнопки стоит на месте. `RevealGroup`: открыта последняя кнопка, на которую пришёл указатель, и остаётся открытой, пока указатель в ряду (в том числе над промежутками), — кнопка не убегает из-под мыши и соседняя не пропускается (проверено проходом курсора в обе стороны). Шапка — тем же компонентом, размер 34 | Павел, ревью 2026-10-13 (было: поверх соседей) |
| Плашка имени | **Как в 0.1:** аватар 44 и имя на плашке поверх верхнего края панели; кнопка «Голос» — в плашке после имени. Текст всегда начинается в одной точке | Павел, ревью 2026-10-13 (было: портрет внутри панели по макету) |
| Вопрос развилки | **Как в 0.1:** когда выходят варианты, вопрос «отступает» — приподнят, приглушён, обрезан до одной строки; обрезанный целиком в подсказке (`Tooltip`, `useIsTruncated` возвращены). Варианты — строки текста со свечением и точкой, как в 0.1. Выходят после клика по вопросу | Павел, ревью 2026-10-13 |
| Размер панели | **Не меняется:** тело держит три строки (реплика в две, или вопрос и два варианта); кнопки — в углу над первой строкой, мета-строка — в нижнем поле справа, обе не участвуют в раскладке текста. На повествовании, реплике и развилке панель одной высоты (217 px на 1920×1080, как в 0.1) | Павел, ревью 2026-10-13 |
| Фон сцены | Не менялся: верхние 75 % окна, `cover`. Казался меньше снизу, потому что новая панель была ниже и открывала тёмную полосу под картинкой (61 px вместо 45) — с панелью 0.1 вернулось как было | ревью 2026-10-13 |
| Индикатор Auto / Skip | Не сделан сейчас (спецификация: «готов, но не показывается») — придёт с этапом 2, где есть режимы: мёртвый компонент не держим | по факту |
| Время игры | Часы в `GameStore`: идут, пока открыт экран игры, вкладка видима и игровое меню закрыто (Ren'Py не считает меню); остановка часов пишет автосейв — время с последней реплики не теряется. Поле `playTime` — в сейве движка рядом с `savedAt` (`SaveMeta`), необязательное, без новой версии формата | по факту |
| Настройки — значения | Громкости по умолчанию наши (100 / 50 / 100), шаг 1 %; скорость 10–120 зн/с и «Мгновенно»; окно диалога 40–100 %, по умолчанию 96 %; размер текста 15 / 16,5 / 18,5. Голос — строки неактивны с подсказкой «Появится вместе с озвучкой». Полноэкранный режим не хранится: состояние берётся у браузера | по факту |
| Языки | Самоназваниями в любом языке интерфейса: «Русский» / «English» (`languageNames`) | по факту |
| Подтверждение «Новой игры» | По макету: «Начать новую игру? Автосохранение будет перезаписано.», кнопка «Начать» — опасный (красноватый) вариант | по факту |
| Арт главного меню | Фон `room` и спрайт Милы — `content/assets.ts → menuArt`, через `RootStore` | спецификация |
| Модальное окно | `shared/ui/Modal` — только фон, Esc, фокус и роль; вид окна задаёт тот, кто его использует (`styled(Modal)`). Сетка фона с явными дорожками — окно меньше экрана на телефоне и прокручивается внутри | по факту |
| Общие константы | Раздел меню — `shared/config/gameMenu.ts`; размеры текста и минимальная непрозрачность — `shared/config/settings.ts`: их видят и стор, и фича | по факту |
| Линтер | `only-export-components` знает `observer` (`customHOCs`) | по факту |

## Что вошло

- **Движок:** `SaveMeta { savedAt, playTime }`, `playTime` в схеме сейва (необязательное).
- **Контент:** `sceneTitles` (+ en), `menuArt`; `collectStoryText` собирает и названия сцен.
- **Сторы:**
  - `GameStore` — часы времени игры, `resumable` с метаданными, `sceneTitle`, `continuePreview`, `frameOf`;
  - `SettingsStore` — `muted`, `textSize`, `windowOpacity`, `reset()`;
  - `UiStore` — `overlay` объектом (`gameMenu` с разделом / `confirmNewGame`), `showMenuSection`, тон уведомления;
  - `RootStore` — `menuArt`, `setMuted` в аудио.
- **`shared`:**
  - `ui/` — `PlainButton`, `RevealButton` + `RevealGroup`, `ActionButton`, `Switch`, `Segmented`, `Slider` и `Modal` по макету;
  - `lib/` — `format.ts` (+ тест), `useFullscreen`, `usePageVisible`, `useNow`;
  - `config/` — `gameMenu.ts`, `settings.ts`;
  - `i18n` — новые ключи, `languageNames`;
  - удалены `IconButton`, `PillButton`, `Button`; `Tooltip` и `useIsTruncated` остаются — для обрезанного вопроса развилки.
- **`entities/frame`** — `StageFrame`, `FrameThumbnail`; удалены `entities/background` и `entities/character`.
- **`features/change-settings`** — `SettingsSection`; удалены `SettingsControls`, `SettingsRows` и `features/switch-language`.
- **`features/make-choice`** — варианты как в 0.1, размер текста из настроек.
- **`widgets/`:**
  - `dialogue-box` — раскладка 0.1 (плашка имени, три строки, «отступающий» вопрос) с новым: «Голос», кнопки-иконки, мета-строка, размер текста и непрозрачность из настроек;
  - `game-header`, `game-menu` (новый), `continue-card` (новый), `confirm-dialog` и `notice` — по макету;
  - `scene-view` — на `entities/frame`;
  - удалён `settings-overlay`.
- **`pages/`** — `GamePage` (часы, мета-строка, заглушки), `MainMenuPage` (по макету).
- **Тема** — переписана по макетам.
