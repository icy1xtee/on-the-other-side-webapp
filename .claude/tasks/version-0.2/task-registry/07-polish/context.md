## Что вошло

- **`shared/config/keymap.ts`** — список клавиш (+ тест: каждой клавише — действие, вход не занят дважды, каждое действие в окне ровно раз).
- **`features/view-controls`** — `ControlsSection` (раздел, подсветка), `useControlsKey` (F1).
- **`shared/ui`** — `Keycap`, `MouseGlyph`.
- **`features/advance-dialogue`** — клавиши по keymap.
- **Сторы** — `UiStore.openControls` (+ тест); раздел `controls` в `MENU_SECTIONS`; главное меню — «Загрузить», «Настройки», «Управление».
- **Тема** — `controls`, `keycap`, цвета и свечения клавиш, размеры шрифта.
- **Словари** — раздел, группы, действия, названия клавиш и мыши, обе локали.
- **e2e** — `controls.spec.ts`: F1 в игре, клавиши в окне игру не трогают; «Управление» из главного меню.
- **Документы** — README (состояние 0.2, F1), CLAUDE.md (keymap, view-controls, правило слоёв), план приведён к факту, ретроспектива и бэклог 0.3 — в [журнале версии](../../progress.md).
- **Версия** — `0.2.0`.
