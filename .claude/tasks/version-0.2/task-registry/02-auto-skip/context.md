# Этап 2. Auto и Skip — контекст

Исходная спецификация — [../../02-auto-skip.md](../../02-auto-skip.md). Ход работ —
[progress.md](./progress.md). Решения планирования — [plan-0.2.md](../../../../plan-0.2.md).

---

## Цель

«Авто» и «Пропуск» работают как в Ren'Py; прочитанное переживает новую игру (`ots:persistent`).

## Опирается на

- Этап 1 — состояние чтения в сторе, расширенное демо.
- Этап 0 — индикатор `AUTO` / `SKIP`, строки настроек из макета.

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Auto | Как в Ren'Py: клик выключает, на развилке ждёт (решение 17); пауза — постоянная после допечатки, при мгновенном тексте + время на чтение (решение 21) | планирование, Павел, 2026-10-12 |
| Skip | Как в Ren'Py: прочитанное (настройка «Всё»), стоп на развилке, Ctrl / Tab, без переходов (решение 18) | планирование, Павел, 2026-10-12 |
| Прочитанное | Ключ «сцена + русская строка», `ots:persistent` (решение 19) | планирование, Павел, 2026-10-12 |
| `PersistentStore` | Ren'Py `persistent`, пока только прочитанное: `ots:persistent` = `{ readLines: [...] }`. Ключ — `сцена:хэш(русская строка)`: id сцены читается глазами, текста истории в хранилище нет. Битые данные — «ничего не прочитано»; хранилище отказывает — отметки живут до конца сессии; пишется только новая отметка. Dev-запуски (`?dev=`) — в своём `ots:persistent:dev` | по факту |
| Хэш | `hashText` из движка — тот же cyrb53, что у `sceneHash`; публичный API движка вырос на одну функцию, копии алгоритма в приложении нет | по факту, к ревью |
| Когда «прочитано» | **Когда реплику прошли**, а не когда показали: так в Ren'Py — `renpy.is_seen()` во время показа говорит о прошлых разах, отметка ставится по завершении. Вопрос развилки — прочитан, когда выбран вариант. Спецификация говорила «когда показана» — поправлено | Ren'Py, к ревью |
| Режимы — где | `ReadingStore.mode` (`'auto'` / `'skip'` / нет) и `skipHeld` (Ctrl). Стор говорит, что режим сделает дальше и когда (`nextStep`: `advance` / `reveal` / `stop` + задержка), и делает это (`step()`). Таймер — в UI (`useReadingModes`), как rAF печати: только пока игрок на экране игры, вкладка видна и окно не открыто. В скрытой вкладке Auto не листает | по факту |
| Auto — тайминг | `autoForwardMs`: «Задержка автоперехода» (0,5–6 с, шаг 0,5, по умолчанию 2) после допечатки; при мгновенном тексте + `(длина + 25) / 250 × 4 с` — формула Ren'Py, `afm_time` = 4 с (средняя реплика демо читается так же, как печатается на 38 зн/с). Длина — по русскому исходнику | Ren'Py; T — по факту |
| Auto — развилка | Вопрос читается сам (варианты выходят после паузы), выбор — за игроком; после выбора Auto листает дальше | по факту, к ревью |
| Skip — тайминг | Ren'Py `config.skip_delay` = 5 мс: прочитанная реплика сразу целиком, следующая — через 5 мс (на деле кадр-два). Растворение кадра выключено (`SceneView instant`) | Ren'Py, к ревью |
| Skip — правила | Режим «Прочитанное»: первая непрочитанная реплика останавливает пропуск, она печатается как обычно. На развилке — стоп; вопрос, прочитанный раньше, выходит прочитанным, с вариантами. После выбора не продолжает. Ctrl на непрочитанной — ждёт, пока держат (как в Ren'Py: дочитал — пропуск пойдёт дальше) | Ren'Py |
| Skip — звуки | Играют: Ren'Py `config.skip_sounds = False` по умолчанию. Музыка — как обычно | Ren'Py, к ревью |
| Клик в режиме | Выключает Auto или Skip и больше ничего — реплика не переходит (Ren'Py: `SayBehavior` при `afm_after_click = False` и при пропуске) | Ren'Py |
| Кто выключает | Клик, Space, Enter; включение другого режима; `RootStore` — уход с экрана игры или открытое окно (игровое меню, главное меню, конец игры) | спецификация |
| Строка пропуска остаётся целой | Если пропуск остановился на прочитанной реплике (клик, отпущен Ctrl), она не печатается заново — стор запоминает её показанной | по факту |
| Клавиши | Tab — Skip вкл / выкл, если фокус не на кнопке; на кнопке Tab двигает фокус, Shift+Tab — всегда (кнопки панели остаются доступны с клавиатуры). Ctrl — пропуск, пока зажат; отпускание ловится и по `blur` окна (Ctrl+Tab в браузере) | по факту, к ревью |
| Индикатор | `widgets/mode-indicator`: плашка макета под шапкой слева, `AUTO ▸` / `SKIP ▸▸` (так и в русском интерфейсе, как в макете); место под неё всегда есть, `aria-live` объявляет режим | макет |
| Кнопки | «Авто» и «Пропуск» — `aria-pressed`, подсвечены, пока режим идёт (Ctrl-пропуск тоже подсвечивает «Пропуск») | макет |
| Настройки | Вкладка «Текст»: «Задержка автоперехода» — ползунок 0,5–6 с, «2,0 с»; «Пропуск» — «Прочитанное» / «Всё». В `SettingsStore` — `autoDelay`, `skipMode` | макет |

## Что вошло

- **Движок:** `hashText` в публичном API.
- **Сторы:** `PersistentStore`; `ReadingStore` — режимы, `nextStep` / `step`, отметки прочитанного, `choose`; `SettingsStore` — `autoDelay`, `skipMode`; `RootStore` — `persistent` и остановка режимов.
- **`shared`:** `ots:persistent` (+ dev), `AUTO_DELAY`, `SKIP_MODES`, `formatTenths`.
- **`features/advance-dialogue`:** Tab, Ctrl; `useReadingModes` — таймер режимов.
- **`widgets`:** `mode-indicator` (новый), `dialogue-box` — нажатые кнопки, `scene-view` — без перехода при пропуске.
- **`features/change-settings`:** две строки во вкладке «Текст».
- **e2e:** `modes.spec.ts` — Tab-пропуск, Ctrl-пропуск, Auto до развилки и после.
