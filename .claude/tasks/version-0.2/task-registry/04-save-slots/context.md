# Этап 4. Слоты — контекст

Исходная спецификация — [../../04-save-slots.md](../../04-save-slots.md). Ход работ —
[progress.md](./progress.md). Решения планирования — [plan-0.2.md](../../../../plan-0.2.md).

## Цель

6 ручных слотов и автосейв, разделы «Сохранить» и «Загрузить» по макету; сейв v2 с журналом и стеком отката.

## Опирается на

- Этап 3 — журнал и стек.
- Этап 0 — миниатюра кадра, `ConfirmDialog`, уведомления, время игры.
- Версия 0.1 — `engine/save` (версия, `sceneHash`, миграции).

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Слоты | 6 ручных + автосейв, только загрузка (решение 10) | планирование, Павел, 2026-10-12 |
| Миниатюра | Из сейва, не скриншот (решение 11) | планирование, Павел, 2026-10-12 |
| Быстрый слот | Нет (решение 12) | планирование, Павел, 2026-10-12 |
| Стек в сейве | Да (решение 16); хэши всех сцен стека — изменившаяся обрезает откат | планирование, Павел, 2026-10-12 |
| Esc | Игровое меню на «Сохранить» (решение 28) | планирование, Павел, 2026-10-12 |
| Путь игрока — в движке | `timeline.ts` переехал из `src/app/stores` в `engine/timeline/` и экспортируется из `@engine`: сейв хранит путь целиком, а восстановление пути (хэши сцен, обрезка стека, перезапуск сцены) — дело движка. Код и тесты — без изменений | по факту; ревью — ок (Павел, 2026-10-14) |
| Формат v2 | `{ version: 2, checkpoints, current, history, sceneHashes, savedAt, playTime }` — сериализованный `Timeline`: игра на экране — `checkpoints[current]`, старше — путь назад, новее — путь вперёд, по которому откатились. Отдельного состояния сверху нет (не дублируется). `playTime` обязательное. Вариант журнала — `discriminatedUnion` по `kind` | по факту; ревью — ок (Павел, 2026-10-14) |
| Путь вперёд в сейве | Сохраняется: после загрузки PageDown идёт вперёд, как до сохранения | по факту; ревью — ок (Павел, 2026-10-14) |
| Миграция v1 → v2 | Состояние v1 — единственная точка без записей; журнал пустой; `sceneHashes` из `sceneHash`; время 0, если не было. Реплика на экране в журнал не попадает (по спецификации: «журнал и стек пустые») | спецификация |
| Изменившаяся сцена | Точка «целая», если сцена есть, хэш совпал и на шаге реплика или развилка. Сцена на экране изменилась — она с начала с сохранёнными переменными (как в 0.1): движок прогоняет её до первой реплики (`run`, звуки не играют, музыка — из состояния), в журнале новая первая реплика вместо старой, выбор, который привёл сюда, остаётся; пути вперёд нет. Откат — до ближайшей изменившейся точки (её и всё старше — долой), путь вперёд — до первой изменившейся. Журнал не обрезается: прочитанное остаётся прочитанным. Сцены нет или в ней не осталось реплик — сейв не загружается, причина в консоль | спецификация; детали по факту |
| `restoreSave` | Возвращает `{ ok: true, timeline }` или `{ ok: false, reason }` — как `parseSave`; причина идёт в консоль («Slot 3 ignored: …») | по факту |
| Размер сейва | Демо целиком (30 точек, 31 запись) — ≈12 тыс. символов (≈24 КБ в UTF-16); полный стек (129 точек, 250 записей) — ≈62 тыс. символов (≈122 КБ). Порог 150 КБ не превышен — стек хранится целиком. Запись полного сейва в Chrome ≈0,3 мс (stringify 0,12 + setItem 0,17) — автосейв на каждой реплике, Skip каждые 5 мс — не заметно | замер |
| Хранилище | `saveKey(source, dev)`: `ots:save:auto`, `ots:save:1` … `ots:save:6`; `?dev=` — `ots:save:dev`, `ots:save:dev:1` … `RootStore` получает `saveStorage: (source) => StorageSlot`, `SaveStore` открывает все семь при создании. Типы — `shared/config/saveSlots.ts`: `SAVE_SLOTS`, `SaveSlot`, `LoadSource` (`SaveSlot \| 'auto'`), `SlotQuestion` | по факту |
| `SaveStore` | `resumable` — автосейв (`SavedGame`: путь, `savedAt`, `playTime`); `slots` — заполненные слоты, читаются `readSlots()` при открытии раздела (в `useLayoutEffect` — до первой отрисовки); `game(source)`, `preview(source)` (кадр, сцена, реплика, дата — через `presentation.savePreview`), `saveTo(slot)` — игру на экране в слот, `deleteSlot(slot)`. `saveNow` больше нет. Битый слот — в консоль и пустой | спецификация; API по факту |
| Загрузка | `GameStore.resume(saved)` — и «Продолжить», и «Загрузить»: время из сейва, путь целиком, переход по точке как при откате — кадр сразу (`travelled`, Ren'Py `after_load_transition = None`), без звуков, музыка из состояния с `ifChanged`; автосейв сразу пишет загруженную игру. Реплика печатается заново, вопрос развилки надо дочитать — как «Продолжить» раньше. `continueGame` / `continuePreview` из `GameStore` убраны: превью — `saves.preview('auto')` | спецификация; детали по факту; ревью — ок (Павел, 2026-10-14) |
| Вопросы над меню | `UiStore`: у оверлея игрового меню поле `question` (`overwrite` / `delete` / `load`), `ask`, `dismissQuestion`; смена раздела вопрос снимает. `RootStore`: `requestSave` (пустой — сразу, занятый — спросить), `requestLoad` (в игре — спросить, из главного меню — сразу), `requestDelete` (спросить), `confirmQuestion`. После записи — «Сохранено в слот N» или ошибка «Не удалось сохранить: хранилище браузера недоступно» | спецификация, макет |
| Окно поверх окна | Вопрос рисуется внутри окна меню (`GameMenu` → `dialog`), как в макете: затемняет только окно; меню под ним `inert`. `Modal` ведёт стек открытых окон — Esc закрывает только верхнее; закрываясь, вложенное окно возвращает фокус туда, где он был (на слот), а если того уже нет (слот удалён) — в окно под ним | по факту |
| `ConfirmDialog` | Переехал из `widgets/confirm-dialog` в `shared/ui`: это примитив без логики, а вопрос о слоте рисует фича `save-slots` | по факту; ревью — ок (Павел, 2026-10-14) |
| Раздел слотов | `features/save-slots/SlotsSection` по макету `Game Menu` (`isSlots`): сетка 3×2; занятый слот — миниатюра 16:9 (`FrameThumbnail`), мета `СЛОТ 3 · 14.10.2026 · 12:43`, название сцены, начало реплики «Мила: …» в одну строку; пустой — «Пустой слот» пунктиром (в «Загрузить» — неактивная кнопка). «Загрузить» — карточка «Автосохранение» над сеткой. Заголовки окна — «Сохранение» / «Загрузка» (ключи `gameMenu.title.*`) | макет |
| Корзина | `Trash2` поверх миниатюры, появляется при наведении и фокусе на слоте (CSS `:hover` / `:focus-within`), остаётся в порядке Tab. Delete на сфокусированном слоте — тоже вопрос об удалении (Ren'Py `save_delete`) | макет; Delete — по факту; ревью — ок (Павел, 2026-10-14) |
| Мета-строка | Разрядка 0,12em вместо 0,18em макета: при 0,18em время не влезает и обрезается («12:…») — в самом макете тоже. Время — 24-часовое во всех языках (`hourCycle: 'h23'`), и в карточке «Продолжить» | по факту; ревью — ок (Павел, 2026-10-14) |
| Автосейв в «Загрузить» в игре | Показан, как в макете, хотя это и есть игра на экране (автосейв пишется на каждой реплике): загрузить его — вернуться туда же | макет; ревью — ок (Павел, 2026-10-14) |
| Миниатюра «Продолжить» | Персонажи всегда по центру (`FrameThumbnail centered`), где бы ни стояли на сцене: квадрат карточки показывает только середину кадра. В слотах и автосейве — как на сцене | Павел, ревью этапа 4, 2026-10-14 |
| Входы | «Сохранить» и «Загрузить» в панели открывают свои разделы (решение 0.1 «„Сохранить“ пишет в автосейв» закончилось); Esc — меню на «Сохранить»; в главном меню — пункт «Загрузить» между «Новой игрой» и «Настройками»; разделы в игре — «Сохранить», «Загрузить», «История», «Настройки», из главного меню — «Загрузить», «Настройки» | спецификация, макет |

## Что вошло

- **Движок:** `timeline/` (переехал из `src/app/stores`); `save/` — схема v2, миграция v1 → v2, `createSave(timeline)`, `restoreSave` → путь или причина; README.
- **Сторы:** `SaveStore` — слоты, превью, `SavedGame`; `GameStore` — `resume`, автосейв пути; `UiStore` — вопрос над меню; `RootStore` — сохранение, загрузка, удаление с вопросами; `presentation.ts` — `savePreview`.
- **`shared`:** `config/saveSlots.ts` (новый), `config/storageKeys.ts` — `saveKey`, `config/gameMenu.ts` — разделы `save`, `load`; `ui/ConfirmDialog` (переехал), `ui/Modal` — стек окон, возврат фокуса; `lib/format` — 24-часовое время; словари — слоты, вопросы, «Сохранено в слот N», «Загрузить».
- **`features`:** `save-slots` — `SlotsSection`, `SlotQuestionDialog` (новые); `advance-dialogue` — Esc на «Сохранить».
- **`widgets`:** `game-menu` — разделы, заголовки, окно поверх окна.
- **`pages`:** игра — кнопки панели; главное меню — «Загрузить», превью из `SaveStore`.
- **`entities`:** `frame` — `FrameThumbnail centered` для карточки «Продолжить» (ревью).
- **Тема:** `slots`, цвета слотов, пустых слотов и корзины, размеры шрифтов.
- **e2e:** `slots.spec.ts` — сохранить → новая игра → загрузить (вопрос в игре) → та же реплика, история, откат; из главного меню после перезагрузки — сразу; перезапись и удаление с вопросами.
