## Открытые вопросы спецификации

| Вопрос | Тип | Статус |
|---|---|---|
| Размер сейва v2 | по факту | **закрыт**: демо целиком — ≈12 тыс. символов (≈24 КБ в UTF-16); полный стек (129 точек, 250 записей) — ≈62 тыс. символов (≈122 КБ). Меньше порога 150 КБ — стек хранится целиком, как в памяти. Запись в Chrome ≈0,3 мс |
| Delete на слоте удаляет его | по факту | **закрыт**: да, как `save_delete` в Ren'Py — но через тот же вопрос «Удалить сохранение?», что и корзина |

### 2026-10-14 · этап целиком · на проверке

Ветка создана Павлом от `main` после PR #15.

**Сделано:**
- **Сейв v2** — путь игрока целиком: точки отката (назад и вперёд), журнал, хэши всех сцен пути, время игры обязательное. Миграция v1 → v2. Изменившаяся сцена: на экране — с начала, откат обрезается на ней; игра не падает.
- **Путь в движке** — `timeline.ts` переехал в `engine/timeline/`, сохранение и восстановление пути — в `engine/save`.
- **Слоты** — `ots:save:1` … `ots:save:6`; `SaveStore` — слоты, превью для меню, запись, удаление; битый слот — в консоль и пустой; отказ хранилища — уведомление.
- **«Сохранить» и «Загрузить»** — разделы игрового меню по макету: сетка 3×2 с миниатюрами, автосейв карточкой над сеткой в «Загрузить», корзина на наведении и фокусе, Delete; вопросы о перезаписи, удалении и загрузке в игре — поверх окна меню; из главного меню загрузка сразу.
- **Загрузка** — как «Продолжить»: та же реплика, журнал, путь назад и вперёд, музыка с `ifChanged`, время из сейва.
- **Входы** — кнопки панели, Esc на «Сохранить», «Загрузить» в главном меню.
- **Окна** — Esc закрывает только верхнее, фокус возвращается на слот.

**Проверено:**
- `lint`, `typecheck`, `test` (221, было 196: сейв v2, миграция, обрезка стека, перезапуск сцены, слоты, вопросы в `RootStore`, загрузка в `GameStore`), `format:check`, `build` (JS 521 КБ / gzip 157 КБ, было 503 / 152).
- `npm run e2e` — 14 тестов, из них 3 новых:
  - сохранить в слот → новая игра → загрузить с вопросом → та же реплика, история на месте, откат работает;
  - из главного меню после перезагрузки слот загружается сразу;
  - перезапись и удаление — с вопросами.
- Прод-сборка, скриншоты 1920×1080, 2560×1080, 1024×768, 844×390: разделы по макету, корзина на наведении, вопрос затемняет только окно меню. Клавиатура: Esc закрывает только вопрос, фокус возвращается на слот, Delete спрашивает, после удаления фокус в окне меню. Ошибок в консоли нет.
- Замер размера сейва и цены записи — см. открытые вопросы.
