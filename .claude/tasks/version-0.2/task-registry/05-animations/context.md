# Этап 5. Анимации — контекст

Исходная спецификация — [../../05-animations.md](../../05-animations.md). Ход работ —
[progress.md](./progress.md). Решения планирования — [plan-0.2.md](../../../../plan-0.2.md).

---

## Цель

`fade`, `move`, `vpunch` опцией `with`, как в Ren'Py; явный переход реплика ждёт.

## Опирается на

- Версия 0.1 — `widgets/scene-view`: растворение кадра, одно состояние на реплику.
- Этапы 2–3 — без переходов при Skip и откате.

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Набор | `fade`, `move`, `vpunch`; остальные — когда понадобятся (решение 29) | планирование, Павел, 2026-10-12 |
| Ожидание | Явный переход ждёт, клик доматывает; растворение не ждёт; при Skip переходов нет (решение 30) | планирование, Павел, 2026-10-12 |
| Где переход | Эффект в `RunResult`, как музыка: в сейв не попадает | планирование, Павел, 2026-10-12 |
| Ren'Py: параметры | По документации: `fade` = `Fade(0.5, 0, 0.5)` — в чёрный за 0,5 с, из чёрного за 0,5 с; `move` = `MoveTransition(0.5)` — сменившие место едут **равномерно** (плавный разгон — это отдельный `ease`), новая картинка подставляется сразу, появившиеся и ушедшие — сразу, остальное в кадре — сразу; `vpunch` = `Move((0, 10), (0, -10), .10, bounce=True, repeat=True, delay=.275)` — кадр вверх-вниз на 10 px, полкачания 0,1 с, всего 0,275 с | доки Ren'Py |
| Движок | `TRANSITIONS`, тип `Transition`; у `scene`, `show`, `hide` — `with?`; `applyInstant` отдаёт эффект `{ type: 'transition', transition }`, `run` собирает все по порядку. В состоянии и сейве перехода нет. У сцены без `with` команда без ключа — отпечаток сцены не меняется | спецификация |
| DSL | `scene('street', { with: 'fade' })`, `show('mila', 'sad', 'left', { with: 'move' })`, `show('mila', 'sad', { with: 'vpunch' })`, `hide('mila', { with })` | спецификация |
| Один переход на реплику | `presentation.frameTransition(effects)` — последний `with` до реплики. `GameStore.transition` — `{ kind, key }`, ключ новый на каждый шаг; после отката, прокрутки вперёд и загрузки — `null` | спецификация; ревью — ок, пересмотреть на реальном контенте (Павел, 2026-10-14; в Ren'Py несколько `with` идут подряд) |
| Ожидание в `ReadingStore` | `transition` — переход, пока он идёт: `null`, когда кончился, его доматали или идёт Skip (включённый Skip закрывает переход насовсем). Пока идёт: `lineShown` ложно, `choiceOptions` нет, Auto не считает паузу; `requestAdvance` доматывает переход и больше ничего не делает; `transitionEnded(key)` — от сцены | спецификация; API по факту |
| Сцена | `SceneView` получает `transition` и `onTransitionEnd`. Время перехода держит таймер, а не конец анимации: у `move` без движения анимации нет, а реплика всё равно ждёт. Доматанный переход (проп стал `null`) — сразу новый кадр. `fade` — слой чёрного поверх нового кадра, под ним гаснет старый; на старте игры — из чёрного. `move` — `StageFrame movedFrom`: сменившие колонку едут от старой (`left` по CSS-переменной), линейно. `vpunch` — сдвиг слоя кадра по ключевым кадрам из `punchMs` / `punchSwingMs` / `punchPx`; трясётся только сцена | по факту |
| Панель во время перехода | Остаётся, пустая: без плашки имени, текста и вариантов; реплика печатается после перехода (`useTypewriter` — `held`) | спецификация; ревью — ок, пересмотреть на реальном контенте (Павел, 2026-10-14; в Ren'Py окна во время `scene … with fade` не видно) |
| Меньше движения | `useReducedMotion` (`shared/lib`): `fade` — растворение 200 мс, `move` и `vpunch` — нет, реплика их не ждёт | спецификация |
| Демо | Стук в дверь — `show('mila', 'sad', { with: 'vpunch' })` (Мила грустнеет на стуке, а не строкой позже); Мила отходит от двери — `show('mila', 'sad', 'left', { with: 'move' })` перед «Кто это может быть?»; улица и дом — `scene(…, { with: 'fade' })`. Первая сцена — без `fade`: первый кадр и так проявляется из чёрного | по факту; ревью — ок (Павел, 2026-10-14) |

## Что вошло

- **Движок:** `types/command.ts` — `TRANSITIONS`, `Transition`, `with`; `state/applyInstant.ts` — эффект перехода; тесты; README.
- **Контент:** `dsl.ts` — опция `with`; сцены — `vpunch`, `move`, два `fade`; тесты фабрик и демо (все три перехода по пути).
- **Сторы:** `presentation.ts` — `frameTransition`, `TransitionView`; `GameStore.transition`; `ReadingStore` — ожидание, `transitionEnded`; `audioEffects` пропускает переход; тесты (`staged` в `testStory`).
- **`shared`:** `lib/useReducedMotion.ts` (новый), `lib/useTypewriter.ts` — `held`.
- **`entities`:** `frame` — `StageFrame movedFrom`.
- **`widgets`:** `scene-view` — `fade`, `move`, `vpunch`, меньше движения, конец перехода.
- **`features` / `pages`:** `advance-dialogue` — машинка ждёт переход, панель пустая; игра — переход в сцену.
- **Тема:** `timing` — `fadeOutMs`, `fadeInMs`, `reducedFadeMs`, `moveMs`, `punchMs`, `punchSwingMs`, `punchPx`.
- **e2e:** `transitions.spec.ts` — реплика ждёт `fade`, нажатие доматывает; при «меньше движения» — короткое растворение.
