## Цель

`fade`, `move`, `vpunch` опцией `with`, как в Ren'Py; явный переход реплика ждёт.

## Опирается на

- Версия 0.1 — `widgets/scene-view`: растворение кадра, одно состояние на реплику.
- Этапы 2–3 — без переходов при Skip и откате.

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Набор | `fade`, `move`, `vpunch`; остальные — когда понадобятся (решение 29) | планирование, Павел, 2026-10-12 |
| Ожидание | Явный переход ждёт, клик доматывает; растворение не ждёт; при Skip переходов нет (решение 30) | планирование, Павел, 2026-10-12 |
| Где переход | Эффект в `RunResult`, как музыка: в сейв не попадает | планирование, Павел, 2026-10-12 |
