# Этап 3. Рендер сцены — контекст

Исходная спецификация — [../../03-rendering.md](../../03-rendering.md). Ход работ —
[progress.md](./progress.md).

---

## Цель

Первый играбельный билд: линейная сцена проходится от начала до конца мышью и с клавиатуры,
текст печатается, клик во время печати доводит реплику. Точка «оно живое».

## Опирается на

- **Этап 1** — кадр 1920×1080 со слоями, тема, меню.
- **Этап 2** — движок в `engine/`, `GameStore` (`state`, `interaction`), `AppStores`,
  контент с фабриками и демо-сценами.
- **Дизайн из Claude Design** — `.claude/ref/html/on-the-other-side-demo-layout-design.html`
  (в `.gitignore`), демо-арт в `.claude/ref/images/`.

## Решения

| Решение | Суть |
|---|---|
| Кто продвигает диалог | **Любой клик по кадру**, кроме системных элементов (`button`, `a`, поля, `[data-system-control]`) — решение Павла. Space и Enter — то же действие; Esc — меню |
| Один путь продвижения | `requestAdvance` в `features/advance-dialogue`: печатается — `finish()`, допечатано — `game.advance()`. Клик и клавиши идут в него же |
| Дизайн | Перенесён из Claude Design: Geist / Geist Mono, тёмная палитра с голубым акцентом, шапка с логотипом, нижняя панель реплики с портретом, именем, кареткой и системными кнопками |
| Масштаб дизайна | Дизайн свёрстан под страницу ~1280 px: его px × **1.5** в кадре 1920×1080 — кадр выглядит как дизайн на 1280 |
| Шрифты | `@fontsource/geist` и `@fontsource/geist-mono` (сборки Google Fonts, **с кириллицей**; `@fontsource/geist-sans` — только латиница). Подключаются целыми файлами по весам: в них `unicode-range`, браузер качает только нужные наборы. Файлы по наборам (`latin-400.css`, `cyrillic-400.css`) без `unicode-range` — вместе их подключать нельзя |
| Ассеты | Объявлены в контенте (`content/assets.ts`) — как `image` в Ren'Py; `satisfies` ловит пропущенный фон или эмоцию. Арт из дизайна сконвертирован в WebP: фон 1672×940 (47 КБ), Мила 941×1671 (206 КБ), портрет из дизайна. `street` — SVG-заглушка |
| Отображение | `GameStore` получает `presentation` (`speakers`, `assets`) при сборке и отдаёт готовое: `background` (URL), `sprites` (URL + позиция), `line` (`key`, имя, портрет, текст). Компоненты не знают id контента |
| Печать текста | `useTypewriter` на `requestAnimationFrame` и прошедшем времени: ровный темп, сам замирает в фоне. Скорость 38 зн/с из дизайна; 0 — мгновенно, как `text_cps = 0` в Ren'Py. `key` реплики перезапускает печать, даже если текст тот же |
| `{done}` | Невидимая копия реплики держит финальную высоту, видимая печатается поверх |
| Высота панели | Постоянная: место под имя и две строки есть и у рассказчика — как фиксированный `textbox_height` в Ren'Py |
| Позиции спрайтов | Колонки шириной 518: `right` — колонка дизайна (62%), `left` — её зеркало, `center` — посередине. Спрайт прижат к низу сцены |
| Горячие клавиши | Обработчик в `features/advance-dialogue` на экране игры, а не «один в `app/`» из спецификации: клавиши имеют смысл только в игре, и им нужно состояние печати |
| Удержание Space | Автоповтор (`event.repeat`) игнорируется: зажатый Space не листает сцену. Skip — отдельная функция, не в 0.1 |

## Что вошло

- `src/app/styles/theme.ts` — токены дизайна; `fonts.ts` — Geist.
- `src/content/assets.ts`, `src/assets/{backgrounds,characters,portraits}/`.
- `GameStore`: `presentation`, вычисляемые `background`, `sprites`, `line`.
- `shared/lib/typewriter.ts` (+ тест), `shared/lib/useTypewriter.ts`, `shared/ui/PillButton.tsx`.
- `entities/background/ui/BackgroundLayer.tsx`, `entities/character/ui/CharacterLayer.tsx`.
- `widgets/game-header/GameHeader.tsx`, `widgets/dialogue-box/DialogueBox.tsx`.
- `features/advance-dialogue/` — `useAdvanceDialogue`, `isSystemControl`.
- `widgets/stage/Stage.tsx` — `onClick`, фон кадра из дизайна; `pages/game/GamePage.tsx`.

## Что не вошло

- Работающие системные кнопки (Auto, Skip, History, Save, Load, Choices, настройки) — только
  неактивные заглушки по дизайну.
- Кнопка VOICE, таймкод «CH.04 · SCENE 12», аватар игрока, второй набор кнопок в правом
  верхнем углу из дизайна.
- Выборы (этап 4), сейв (этап 5), звук и настройки (этап 6), переходы (этап 7).

## Готово, когда

- [x] сцена проходится от начала до конца только мышью — сценарий CDP, клики по кадру
- [x] сцена проходится с клавиатуры — Space продвигает (CDP); Enter — тот же код
- [x] клик во время печати доводит реплику, второй идёт дальше
- [x] диалоговое окно не меняет высоту — 199 px на всех репликах, включая рассказчика
- [x] зажатый Space не пролистывает сцену — автоповтор игнорируется (CDP)
- [x] смена эмоции не создаёт второй спрайт — спрайт по ключу тега, в кадре один (CDP)
- [x] рассказчик без плашки имени и портрета
- [x] `lint`, `typecheck`, `test`, `format:check`, `build`
