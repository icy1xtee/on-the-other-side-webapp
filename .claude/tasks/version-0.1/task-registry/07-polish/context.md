## Цель

Закрыть 0.1: fade-переход между сценами, цифры 1–9 для вариантов, ревизия кода, документы по
факту, полный прогон на прод-сборке, ретроспектива и бэклог 0.2.

## Опирается на

Этапы 0–6 — всё, что сделано в 0.1. Решения ревью, которые попали в этот этап:

- цифры 1–9 выбирают вариант развилки (ревью этапа 4);
- целевой браузер — Chrome; экраны, которых нет в макете, рисуются в языке основного
  дизайна (ревью этапа 6).
