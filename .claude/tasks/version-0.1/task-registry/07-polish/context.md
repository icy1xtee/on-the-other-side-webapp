## Цель

Закрыть 0.1: fade-переход между сценами, цифры 1–9 для вариантов, ревизия кода, документы по
факту, полный прогон на прод-сборке, ретроспектива и бэклог 0.2.

## Опирается на

Этапы 0–6 — всё, что сделано в 0.1. Решения ревью, которые попали в этот этап:

- цифры 1–9 выбирают вариант развилки (ревью этапа 4);
- целевой браузер — Chrome; экраны, которых нет в макете, рисуются в языке основного
  дизайна (ревью этапа 6).

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Состав 0.2 | Интерфейс жанра на демо-сцене: слоты сейвов с экраном загрузки, Auto, History, Skip прочитанного (+ `persistent`), rollback, анимации сверх fade, музыка меню, «Без звука», звуковые эффекты, техдолг по шрифтам и треку. Сюжет — 0.3. Не в 0.2: история выборов (Choices), экспорт сейва, достижения, другие браузеры, отдельные дизайны. Подробно — [plan-0.2.md](../../../../plan-0.2.md) | Павел, 2026-10-12 |
| Деплой | После 0.2 | Павел, 2026-10-12 |
| Документы по версиям | `.claude/tasks/version-0.1/`, `version-0.2/`, `plan-0.2.md`; техдолг общий | Павел, 2026-10-12 |
| Переход кадра | Двойной буфер (`widgets/scene-view`): кадр — фон и персонажи вместе; при смене старый кадр растворяется поверх нового, 500 мс (`dissolve`). Переход на **любую** смену кадра — фон, появление, уход, смена эмоции или позиции. Первый кадр — из чёрного. Реплика не ждёт конца перехода. `prefers-reduced-motion` — без анимации | по факту; ревью — Павел, 2026-10-12: оставить |
| «Одним переходом» | Копить изменения не пришлось: движок применяет все мгновенные команды до реплики разом и отдаёт одно состояние — смена фона, уход одного и приход другого персонажа дают одну смену кадра | по факту |
| Цифры 1–9 | Выбирают вариант по порядку на экране (скрытые не считаются), только когда варианты показаны; номеров рядом с вариантами нет | по факту; ревью — Павел, 2026-10-12: оставить |
| Ревизия движка | Убраны мёртвые: `LocalizedText` «строка или `{ $key }`» и `resolveText` (ключом перевода стала сама русская строка), `requiresInteraction` и `InteractionCommand`; `createInitialState` — не в публичном API | по факту; ревью — Павел, 2026-10-12: ок |
| FSD | Фича `change-settings` импортировала соседнюю `switch-language` — теперь их собирает виджет окна настроек | по факту |
| `exactOptionalPropertyTypes` | Не включаем — в 0.1 не понадобилось (хвост этапа 0) | по факту |
