# Этап 5. Save / Load — контекст

Исходная спецификация — [../../05-save-load.md](../../05-save-load.md). Ход работ —
[progress.md](./progress.md).

---

## Цель

Пройти половину сцены, обновить страницу, «Продолжить» — то же место, тот же фон, тот же
персонаж в той же эмоции и позиции, те же переменные. Порченый сейв и отключённое хранилище
игру не роняют.

## Опирается на

- **Этап 2** — состояние движка как plain data (`GameState`: `position`, `vars`, `stage`,
  `audio`), `run()` с позиции без реплея, `variableDefaults`. Решение ревью этапа 2: хэш
  программы сцены в сейве, при несовпадении — сцена с начала с переменными из сейва.
- **Этап 4** — `GameStore` с ключом реплики `сцена:шаг:номер показа`, шаг «подпись прочитана»
  у выбора, dev-сцены по `?dev=`.

## Решения

| Решение | Суть | Чьё |
|---|---|---|
| Формат | `{ version: 1, position, sceneHash, vars, stage, audio, savedAt }` — снапшот, не реплей. `version` — формат сейва, `sceneHash` — содержимое сцены | план + ревью этапа 2 |
| Хэш сцены | cyrb53 от JSON скомпилированной программы (`engine/program/hashProgram.ts`), считается один раз при создании реестра (`registry.getSceneHash`). Любая правка сцены, включая опечатку, меняет хэш; условия `when` — функции, в хэш не входят (шаги не двигают) | по факту |
| Загрузка | `parseSave` (JSON → проверка версии → миграции → `zod/mini`) → `restoreSave` → `run()` выполняет одну команду на сохранённом шаге. Сцена изменилась (хэш не тот, или на шаге не реплика и не выбор) — сцена с начала с сохранёнными переменными; сцены нет — сейва как будто нет | ревью этапа 2 |
| Переменные | Механика `default` из Ren'Py: дефолты истории, поверх — сохранённые значения. Переменная, которой больше нет в истории или чей тип сменился, отбрасывается — иначе условие `when` получит не тот тип | по факту, сверх спецификации |
| Миграции | `engine/save/migrate.ts`: таблица «формат n → n+1», пока пустая. Старый формат без миграции и формат новее текущего отклоняются, а не читаются наугад | спецификация |
| `zod/mini` | Классический `zod` добавлял к бандлу ~94 КБ (+26 КБ gzip), `zod/mini` — ~26 КБ (+6 КБ gzip). Проверка та же; сообщения об ошибках короче («Invalid input» + путь к полю) | по факту |
| Хранилище | Не в движке (там нет DOM), а `shared/lib/storage.ts`: `createStorageSlot(key)` — `localStorage`, который никогда не бросает. Заблокировано, приватный режим, квота, нет хранилища вовсе — чтение пустое, запись `false`, в лог одно предупреждение | по факту (спецификация клала обёртку в `engine/save`) |
| Ключи | Префикс `ots:` (предложение спецификации): `ots:save:auto`; прогоны `?dev=` пишут в `ots:save:dev` и не затирают настоящее прохождение; `ots:settings` — этап 6 | спецификация |
| Автосейв | В `GameStore.apply` на каждой реплике и развилке — «saving occurs at the start of a statement». Запись 206–254 байт за 0–0.1 мс: throttle не нужен | спецификация + замер |
| «Продолжить» | Активна, когда есть что продолжать (`GameStore.canContinue`). Состояние для неё держится и в памяти, поэтому Esc → «Продолжить» работает даже без хранилища. Нет сейва или он испорчен — кнопка неактивна, без сообщений | спецификация |
| Конец игры | Стирает сейв: продолжать нечего, «Продолжить» гаснет | по факту |
| Кнопка «Сохранить» | Пишет в тот же единственный слот и показывает «Игра сохранена» (или «Не удалось сохранить: хранилище браузера недоступно»). Слоты — не в 0.1 | по факту |
| Кнопка «Загрузить» | Остаётся заглушкой «скоро»: загрузка в 0.1 — это «Продолжить» в меню; экран загрузки придёт со слотами | по факту |
| Отказ хранилища | Первый неудавшийся автосейв — уведомление «Сохранение недоступно: прогресс не сохранится», один раз за сессию (ревью, п. 11) | Павел |
| Порченый сейв | Не удаляется из хранилища — его перезапишет следующий автосейв. Сейв из будущей версии игры переживёт откат на старую | по факту |
| Экспорт в файл | Не в 0.1 — записан в план, кандидат в 0.2 | спецификация |

## Что вошло

- `engine/save/` — `schema.ts` (формат, `SAVE_VERSION`, схема `zod/mini`), `migrate.ts`,
  `save.ts` (`createSave`, `parseSave`, `restoreSave`), `save.test.ts`.
- `engine/program/hashProgram.ts`; реестр сцен — `hasScene`, `getSceneHash`;
  `SPRITE_POSITIONS` — один список позиций для типа и схемы.
- `shared/lib/storage.ts` (+ тест), `shared/config/storageKeys.ts`.
- `GameStore` — `saveSlot` в опциях, автосейв, `resumable` / `canContinue`, `continueGame`,
  `saveNow`, чтение сейва при старте; `RootStore.continueGame`; тесты.
- Меню — «Продолжить»; `GamePage` — кнопка «Сохранить»; ключи `notice.saved`,
  `notice.saveFailed`.
- `main.tsx` — слот `ots:save:auto` или `ots:save:dev`.

## Что не вошло

- Слоты, экран загрузки, скриншоты, экспорт в файл — не в 0.1.
- Музыка из сейва: `audio.music` сохраняется и восстанавливается в состоянии, но играть её
  начнёт этап 6.
