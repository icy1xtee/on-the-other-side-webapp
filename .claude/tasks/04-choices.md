# Этап 4. Выборы, переменные, переход между сценами

**Цель:** ветвление работает. Проверяется на отдельном dev-контенте — в игровую линейную сцену
выборы не входят.

**Зависимости:** [этап 3](./03-rendering.md).
**Контекст:** [plan-0.1.md → Этап 4](../plan-0.1.md)

---

## Шаги

### 1. Переменные

- `VarValue = boolean | number | string`
- реестр `variableDefaults` из этапа 2 подключён по-настоящему: движок стартует с дефолтов,
  команда `set` их меняет
- `GameStore.vars` — единственное место, где они живут

### 2. Условия

```ts
type ChoiceOption = {
  text: LocalizedText;
  next: SceneId;
  set?: Array<{ name: VarName; value: VarValue }>;
  when?: (vars: Vars) => boolean;
};
```

**Функция-предикат здесь допустима, и это важно зафиксировать.** Первая редакция плана строила
загрузку на реплее, из-за чего команды обязаны были быть сериализуемыми. После перехода на
снапшот сериализуется только *состояние*, а не команды — значит условие может быть обычной
функцией TypeScript, с автокомплитом по именам переменных. Это прямая выгода от смены модели
сейва, см. [engine-research.md](../engine-research.md).

### 3. `features/make-choice`

- список вариантов: idle/hover из токенов
- недоступный по `when` вариант — **скрывать или показывать неактивным**, см. открытый вопрос
- клик по варианту: применить `set`, затем `jump` в `next`
- клик по варианту **не должен** попутно продвинуть диалог (см. вопрос про всплытие в
  [этапе 3](./03-rendering.md))

### 4. Навигация между сценами

- `jump` из этапа 2 работает и из команды, и из выбора
- фон и спрайты при `jump` не сбрасываются автоматически: за это отвечает команда `scene` в
  начале новой сцены, как в Ren'Py

### 5. Dev-контент

`content/__dev__/branching.ts` — ветвящаяся сцена, в игру не входит. Нужна, потому что игровой
контент 0.1 линейный, а механику надо прогнать. Запуск — через временную кнопку в меню или
флаг в URL (см. открытый вопрос).

### 6. Тесты

- выбор ведёт в указанную сцену
- `set` у варианта применяется до перехода
- `when === false` исключает вариант из доступных
- переменная, которой нет в сейве, берёт значение из `variableDefaults`
- `jump` из выбора не сбрасывает фон и спрайты сам по себе

## Открытые вопросы

- [ ] **(квиз)** Может ли выбор вести не в отдельную сцену, а в ветку внутри текущей? В
      Ren'Py `menu` содержит вложенные блоки, и мелкие развилки не требуют новой сцены. Для
      0.1 предлагаю только `next: SceneId` — проще и достаточно. Но если сценарий будет полон
      мелких реакций, вложенные блоки понадобятся, а это меняет форму `position`.
- [ ] **(доки)** Недоступный вариант: скрывать или показывать серым? Проверить по конвенциям
      жанра — есть аргументы за оба: скрытый не спойлерит, показанный серым сообщает игроку,
      что он что-то упустил. Решение записать сюда.
- [ ] **(квиз)** Как запускать dev-контент: временная кнопка в меню, параметр в URL, или
      переменная окружения на dev-сборку? Кнопка проще всего, но её потом надо не забыть
      убрать.
- [ ] **(по факту)** Нужен ли `set` отдельной командой, если он уже есть у варианта выбора.
      Скорее да — переменные меняются и в линейном тексте, не только на развилках.
- [ ] **(по факту)** Формат `when`: одна функция-предикат или список условий-данных. Функция
      удобнее; проверить, что она не мешает `zod`-валидации сейва на этапе 5 (не должна —
      в сейв попадают только значения переменных, не условия).
