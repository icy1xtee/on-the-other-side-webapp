## Шаги

### 1. Тема и токены

Список токенов подсказал `gui.rpy` из Ren'Py — там за двадцать лет отобралось ровно то, что
новелле нужно. Группы:

| Группа | Токены |
|---|---|
| Геометрия кадра | `stageWidth: 1920`, `stageHeight: 1080` |
| Цвета | фон, текст реплики, цвет имени говорящего, акцент, фон и рамка диалогового окна, idle/hover вариантов выбора |
| Типографика | семейство, размер реплики, **размер имени отдельно от размера реплики**, размер интерфейсного текста, межстрочный интервал |
| Диалоговое окно | высота, внутренние отступы, позиция по вертикали, позиция имени |
| Выборы | ширина варианта, зазор между вариантами |
| z-индексы | фон, спрайты, UI, оверлей |
| Длительности | переход 500 мс, скорость текста по умолчанию (cps) |

Все размеры — в пикселях макета 1920×1080, потому что кадр масштабируется целиком.

Типизация: расширить `DefaultTheme` в `declare module 'styled-components'`, чтобы
`theme.colors.accent` проверялся компилятором.

### 2. Глобальные стили

- reset (в объёме, который реально нужен: margin/padding/box-sizing/шрифт)
- `html, body, #root`: 100% высоты, `overflow: hidden`, фон `#000` — это и есть letterbox
- `user-select: none` там, где выделение мешает клику по кадру
- сглаживание шрифтов, базовый `cursor`

### 3. Stage — масштабируемый кадр

- `useStageScale()` в `shared/lib`: `ResizeObserver` на внешнем контейнере,
  `scale = min(width / 1920, height / 1080)`
- внешний контейнер: `position: fixed; inset: 0`, чёрный фон, центрирование
- сам stage: `width: 1920px; height: 1080px; transform: scale(k); transform-origin: center`
- четыре слоя внутри, каждый `position: absolute; inset: 0`, порядок по z-индексам из темы:
  **фон → спрайты → UI → оверлей**

Раскладка слоёв взята из `SceneLists` Ren'Py: `master` (фон и спрайты), `screens` (UI),
`overlay`. Слой `transient` нам не нужен, это артефакт устройства Ren'Py.

### 4. Сторы и провайдер

- `RootStore` — пока с одним `ui`
- `StoreProvider` через React context, хук `useStores()`
- `UiStore`: `screen: 'menu' | 'game'`, `isSettingsOpen` (задел под этап 6), экшены перехода

### 5. Экраны

- `MainMenuPage`: название игры, «Новая игра», «Продолжить» (неактивна — сейвов ещё нет),
  «Настройки» (неактивна до этапа 6)
- `GamePage`: пустой Stage
- `shared/ui/Button`

Набор экранов сверен со стандартным списком screens в Ren'Py: `main_menu`, `preferences`,
`save`/`load`, `say`, `choice`, `quick_menu`. В 0.1 из них будут `main_menu`, `preferences`,
`say`, `choice`.

## Открытые вопросы

- [ ] **(квиз)** Шрифт. Системный стек или подключаем файл? **Обязательное требование —
      кириллица**, иначе текст игры развалится. Подключённый шрифт даёт предсказуемый вид на
      всех машинах, но это вес и `font-display` возня. Решить до токенов типографики.
- [ ] **(по факту)** Резкость текста при нецелом `scale`. Проверить на реальном абзаце
      русского текста при `scale ≈ 0.63` и `scale = 1.0`, сравнить с вариантом на `cqw`.
      Если мылит заметно — переходим на единицы контейнера, это указано риском в плане.
- [ ] **(доки)** Правильное центрирование при `transform: scale`. Разобраться с дробными
      пикселями и `devicePixelRatio`: нужно ли округлять `scale` или смещение, чтобы
      не появлялась полупиксельная кайма по краям кадра.
- [ ] **(квиз)** Минимальное поддерживаемое разрешение окна. Ниже него можно показывать
      заглушку «разверни окно» вместо нечитаемого кадра.
- [ ] **(по факту)** Нужен ли `will-change: transform` на stage. Добавлять только если увижу
      дёрганье при ресайзе — иначе это лишний слой композитинга.
- [ ] **(квиз)** Визуальный стиль меню и диалогового окна. На этом этапе делаю нарочито
      черновой вид (как и плейсхолдеры арта). Отдельный разговор про дизайн — когда механика
      заработает.
